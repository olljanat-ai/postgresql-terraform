# Password authenticated database owners

Creates a PostgreSQL flexible server with two databases, `orders` and `billing`.
Each database has its own login role that owns it:

| Database  | Owner          | Authentication      |
| --------- | -------------- | ------------------- |
| `orders`  | `orders_owner` | username + password |
| `billing` | `billing_app`  | username + password |

The passwords are generated by the module and `CONNECT` is revoked from
`PUBLIC`, so `orders_owner` cannot connect to `billing` and the other way
around.

## Usage

```bash
export TF_VAR_subscription_id="00000000-0000-0000-0000-000000000000"
export TF_VAR_server_name="psql-example-password"
export TF_VAR_administrator_password="$(openssl rand -base64 24)"
export TF_VAR_client_ip_address="$(curl -s https://api.ipify.org)"

terraform init
terraform apply
```

Read the generated owner passwords afterwards:

```bash
terraform output -json owner_passwords
```

## Requirements

* Azure CLI logged in to the subscription (`az login`).
* Network access from the machine running Terraform to port 5432 of the server.
